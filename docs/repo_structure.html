Repository plan

Chemberta4

A post-training and evaluation framework for chemistry LLMs. Train with full fine-tuning, LoRA or QLoRA on three tasks, then evaluate fine-tuned checkpoints alongside Claude and GPT using the same prompts and metrics.

retrosynthesis: CC(=O)Oc1ccccc1C(=O)O → CC(=O)OC(C)=O . Oc1ccccc1C(=O)O

Three independent axes

TaskData, prompts and metrics. Shared by training and evaluation.tasks/<task>/
MethodFull fine-tuning, LoRA or QLoRA, plus task-specific strategy.training/methods/
BackendClosed-source APIs or local vLLM, behind one interface.evaluation/backends/

Design notes

Configs carry the variation. One train.py and one evaluate.py. The config picks the task and method, so there are no nine near-duplicate scripts to keep in sync.

Tasks are shared. The same prompt format and metrics are used to fine-tune a model and to score Claude, GPT or a vLLM model, so comparisons are fair.

One backend interface. Every model implements generate(prompts) -> list[str]. Checkpoints in outputs/checkpoints/ load straight into the vLLM backend, closing the train-to-eval loop.
